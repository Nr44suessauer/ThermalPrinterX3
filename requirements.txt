# Python dependencies for the X3 thermal printer
# Install with:  pip3 install -r requirements.txt
#
# Additional SYSTEM packages are required (cannot be installed via pip):
#   Debian/Ubuntu:  sudo apt install python3-gi python3-gi-cairo gir1.2-gtk-3.0 \
#                                   python3-pil bluez bluez-tools ghostscript
#   Fedora:         sudo dnf install python3-gobject gtk3 python3-pillow bluez ghostscript
#
# GTK3 + Bluetooth (BlueZ) are part of the operating system; the GUI needs
# python3-gi (PyGObject) in the SYSTEM python (a pip install is not enough).
